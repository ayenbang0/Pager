# pager 1.5.1 plan

## Context

Release pager 1.5.1 (package.json is 1.4.1; CHANGELOG.md has `[Unreleased]`, 1.2.1, 1.1.0, 1.0.0) with: repo-free AI chat tab, a real 1.5.1 changelog, group rename, sidebar folders and sections, more emojis plus message reactions, at-rest encryption plus LAN mode and a no-agents mode, a `⌕ web` search tool tab, a Settings tab that replaces niche slash commands, and a reorganized `src/` tree. Commands after this release (17, was 24): `help code add accept decline open remove group terminal doc agent update changelog search quit exit settings`. No `/folder`, `/react`, `/ai`, `/web`, `/lock` commands exist: those features are UI (sidebar, click, tabs, Settings) or CLI subcommands (`pager lock|unlock`).

Order matters: every step leaves `npm run typecheck && npm test` green. Run both before step 1 and record the passing test count N; every step must end with at least N passing and no failures.

## Step 3: Secrets: passphrase lock for identity.json and pager.db fields

Choice: field-level AES-256-GCM in `Store` (node:sqlite has no SQLCipher). Encrypted: `events.body`, `convs.title`, `peers.name`, `peers.note`, and the identity seed. Plaintext by design: `conv, author, seq, ts, kind, op, sig, recv_at, state`, acks, peer public keys, `settings.json`, `agents-room.jsonl`, `history.json`, `net.log`, agent state files, `ai.json`, `ai-chat.jsonl`. New modules (all with colocated tests):
- `src/chat/secrets.ts`:
  ```ts
  export interface Secrets { identityKey: Buffer; dbKey: Buffer }
  export const SCRYPT = { N: 32768, r: 8, p: 1, maxmem: 64 * 1024 * 1024 } as const
  export function deriveSecrets(passphrase: string, salt: Buffer): Secrets // scryptSync(passphrase.normalize('NFKC'), salt, 64, SCRYPT); [0,32) identityKey, [32,64) dbKey
  export function seal(key: Buffer, plain: Buffer, aad: string): { nonce: Buffer; ct: Buffer; tag: Buffer } // aes-256-gcm, 12-byte random nonce
  export function open(key: Buffer, p: { nonce: Buffer; ct: Buffer; tag: Buffer }, aad: string): Buffer // throws on auth failure
  export const MIN_PASSPHRASE = 8
  ```
- `src/chat/cipher.ts`: `class FieldCipher { constructor(key?: Buffer); seal(plain: string, aad: string): string; unseal(stored: string, aad: string): string; isSealed(stored: string): boolean }`. Sealed form is `pgrenc1:` + base64(nonce(12) | ct | tag(16)). With no key `seal` returns plain; `unseal` of an unmarked value returns it unchanged (plaintext passthrough is required so migration is resumable); `unseal` of a marked value without a key throws `new Error('pager.db is encrypted: a passphrase is required')`.

## Step 11: LAN mode, no-agents mode, secure sessions

### 11a LAN (`pager --lan [host:port]`, or Settings > `lan` + restart)
New `src/net/lan.ts`:
```ts
export interface LanOptions { target?: string; port?: number /* UDP discovery port, default 49737 */; address?: string /* IPv4 to host on, default first non-internal IPv4 */; broadcast?: string[] /* default: 255.255.255.255 + each interface's directed broadcast */; discoverMs?: number /* default 1500 */ }
export interface LanHandle { bootstrap: { host: string; port: number }[]; address: string; hosting: boolean; stop(): Promise<void> }
export async function startLan(opts?: LanOptions): Promise<LanHandle>
```
Protocol: UDP datagram `PGRLAN1?` to the broadcast addresses at the discovery port; a host answers the sender with `PGRLAN1! <ip>:<dhtPort>`. `startLan`: with `target` -> `bootstrap = [parse(target)]`, `hosting=false`, no sockets. Otherwise sleep a random 0-400 ms, send discovery, collect answers for `discoverMs`; any answer -> `bootstrap` from the answers (`hosting=false`). None -> become host: `createTestnet(3, { host: address, port: 0 })` from `hyperdht/testnet.js` (hyperdht 6.34.1 ships it in its `files`; it binds `0.0.0.0` when host is not `127.0.0.1` and returns `bootstrap: [{host, port}]`), bind a UDP socket on the discovery port with `reuseAddr`, answer `PGRLAN1?` with `PGRLAN1! <address>:<bootstrap[0].port>`; if binding fails with `EADDRINUSE` rerun discovery once after 300 ms (another host won the race); if it still fails throw `LAN discovery port <port> is in use`. `stop()` closes the socket and `testnet.destroy()`. No answer within the window while hosting with no network interface -> throw `LAN mode needs a network interface (no non-internal IPv4 address found)`.
`cli.tsx`: when `lan` (flag or effective setting): `const lan = await startLan({ target: parsed.lanTarget })`, call `Engine.open({ ..., bootstrap: lan.bootstrap, lan: { hosting: lan.hosting, address: lan.address } })`, ignore `PAGER_BOOTSTRAP`, skip the update check, and call `lan.stop()` in `shutdown`. Home info lines get `LAN mode: hosting on <addr>` / `LAN mode: joined <addr>`. `EngineOptions.lan?: { hosting: boolean; address: string }`.
LAN restrictions (all via `applyEnvFromSettings` setting `PAGER_LAN='1'`, read through `process.env.PAGER_LAN`): update check skipped; `PAGER_NO_WEB` forced to `'1'` in `cli.tsx` when LAN is on (web rows show locked by `--lan`/`PAGER_LAN`); `isPrivateHost` gate on HTTP AI backends (step 10). CLI agents are not restricted (they may reach the internet themselves; README says so).
